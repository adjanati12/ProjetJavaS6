## Description
Application Java de suivi des étudiants dans une formation à la carte (L3 MIAGE 2025-2026).
Permet de gérer les inscriptions aux UE, le suivi des validations et la progression dans le parcours.

## Technologies
- Java
- Maven
- Base de données

## Lancer l'application
```bash
mvn clean install
mvn exec:java
```
